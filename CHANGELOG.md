## [1.0.0] - 2026-01-07

### 🎉 Первый релиз

Полнофункциональный интернет-магазин для DayZ серверов.

### Добавлено

#### Магазин
- Каталог товаров с категориями
- Фильтрация и поиск товаров
- Корзина покупок
- Оформление заказов
- Список желаний
- Сравнение товаров
- Отзывы и рейтинги
- История цен
- Алерты о снижении цены

#### Пользователи
- Регистрация и авторизация
- Профиль пользователя
- Steam интеграция
- Telegram интеграция
- Discord привязка
- Настройки уведомлений

#### Платежи
- WayForPay интеграция (карты)
- NOWPayments интеграция (крипто)
- Система баланса
- Промокоды
- Flash-распродажи

#### Геймификация
- Ежедневные награды
- Колесо фортуны
- Система достижений
- Реферальная программа
- Программа лояльности

#### Уведомления
- Email уведомления (Resend)
- Push уведомления (PWA)
- Telegram уведомления
- Discord webhooks
- In-app уведомления

#### Админ-панель
- Дашборд со статистикой
- Управление товарами
- Управление заказами
- Управление пользователями
- Промокоды и акции
- Баннеры и контент
- Email кампании
- Поддержка пользователей
- A/B тестирование
- Аудит логи
- Cron задачи

#### Технологии
- React 18.3 + TypeScript
- Vite 5.4
- Tailwind CSS 3.4
- shadcn/ui + Radix UI
- TanStack Query 5
- Supabase (PostgreSQL)
- 19 Edge Functions
- PWA поддержка
- Тёмная/светлая тема

### Безопасность
- Row Level Security (RLS)
- Rate limiting
- Zod валидация
- CORS настройка
- Аудит действий

## Формат версий

- **MAJOR** — несовместимые изменения API
- **MINOR** — новый функционал (обратно совместимый)
- **PATCH** — исправления багов

---

## Типы изменений

- **Added** — новый функционал
- **Changed** — изменения существующего функционала
- **Deprecated** — функционал будет удалён
- **Removed** — удалённый функционал
- **Fixed** — исправления багов
- **Security** — исправления безопасности
